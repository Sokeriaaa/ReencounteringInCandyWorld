# 🍭 再遇糖境

[English](README.md) | **中文**

《糖果世界》（Candy World）模组的新版本移植版（[1.12原作](https://github.com/ochotonida/candymod)：
[ochotonida](https://github.com/ochotonida)，
[1.16 & 1.17移植](https://github.com/Mrbysco/CandyWorld)：[Mrbysco](https://github.com/Mrbysco)）。
《再遇糖境》带回了标志性的糖果生物群系、可爱的生物和美味的工具，为了重温那份甜蜜的回忆与探索的乐趣。踏上旅程，重新发现这个由糖果奇观构成的世界吧！

## 🌌 糖果维度（暂未完成）

进入一个充满糖果的专属维度！虽然部分内容也能在主世界罕见地找到，但糖果维度才是真正冒险的开始。

* **传送器**: 制作并食用一块魔法糖果即可传送至这个甜蜜国度。别担心，使用后物品不会消失，这确保你永远有办法回家。（小提示：建议使用JEI查看合成表哦）
* **可再生**: 更多的魔法糖果会生成在维度本身的地下。

## ⚒️ 可食用的工具与合成

工具怎么能只用不吃呢？新增两种材料类型：**巧克力**和**棉花糖**。

* **可食用工具**: 手持工具时，只需**潜行并右键**即可啃上一口！恢复的饥饿值取决于工具的材料和剩余耐久度。
* **新的工作台**: 为方便起见，维度内会生成自定义的工作台，因此您可以随时随地进行合成，而无需自带工作台。

## 🍬 生物群系

在主世界中探索三个极其甜蜜但罕见的生物群系。若想必定遇到，请前往糖果维度。
现在我们使用[TerraBlender](https://github.com/Glitchfiend/TerraBlender)，将这些美味的群系带进主世界！

### 棉花糖平原

一个蓬松的景观，棉花糖像草一样生长。

* **方块**: 地面由**布朗尼蛋糕**构成，树木的树干是**糖果手杖**制成的。建议带上你的镐子来采集这些甜蜜的树木。
* **资源**: 这里是**棉花糖**的丰富来源。

### 巧克力森林

一个浓郁奢华的森林，巧克力像水一样流淌。

* **方块**: 可以找到**牛奶巧克力、白巧克力和黑巧克力方块**以及**威化棒**。
* **矿石**: **曲奇矿**在这里大量生成，也可以在其他生物群系中找到。

### 软糖沼泽

最充满活力、色彩缤纷的生物群系，地形由五种不同的耐嚼**软糖**方块组成。

* **方块**: 寻找常见于此的巨型**软糖蠕虫**。

## 🐾 生物

遇见这些甜蜜生物群系中可爱（且可食用？）的居民。

### 棉花糖羊

出没于**棉花糖平原**。

* **行为**: 看着像普通的羊，但它的羊毛是由**棉花糖**制成的！
* **收获**: 使用木棍卷上一把棉花糖。它们会通过吃棉花糖草或被施用骨粉来重新长出绒毛。
* **繁殖**: 使用**糖**进行繁殖。

### 复活节鸡

原生于**巧克力森林**。

* **行为**: 会下三种巧克力蛋：**牛奶巧克力、白巧克力和黑巧克力**！
* **加速**: 喂食巧克力会更快地下蛋。
* **繁殖**: 使用**威化棒**进行繁殖。

### 软糖鼠与软糖熊

居住在**软糖沼泽**。

* **软糖鼠**: 胆小的小型生物，如果玩家靠得太近就会逃跑！
* **软糖熊**: 比老鼠更稀有，并有沼泽中五种经典的软糖颜色。
* **行为**: 为充满活力的沼泽增添了更多生机与色彩。
